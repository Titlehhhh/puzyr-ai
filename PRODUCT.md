# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Статические HTML/CSS/JS без сборки и без бэкенда. Ограничение задано брифом: сайт должен работать на GitHub Pages, поэтому сборщик, фреймворк и рантайм-сервер исключены. Шрифты и данные лежат в репозитории или приходят в виде статического JSON-файла.

## Users

Основной посетитель приходит по ссылке из Telegram, X или tech-медиа. Он ничего не настраивает заранее, не знает, что внутри, и у него есть несколько секунд. Его работа: понять, когда лопнет ИИ-пузырь, посмеяться и уйти дальше по ленте, иногда скинув ссылку дальше.

Вторичная аудитория: авторы рассылок и каналов, которые вставляют ссылку в пост как шутку. Для них важно, что ссылка работает без регистрации и что дату можно поменять.

## Product Purpose

Шуточный обратный отсчёт до лопания ИИ-пузыря с дедлайном по умолчанию на конец марта 2028 (31 марта 2028, 23:59 по локальному времени страницы).

Успех: посетитель за первые секунды видит человекочитаемый остаток («1 год 5 месяцев 12 дней»), понимает шутку, видит рядом настоящие котировки AI-компаний и может поделиться ссылкой со своей датой.

## Positioning

Страница, где ИИ-пузырь одновременно и объект шутки, и индикатор: он надувается по мере приближения дедлайна, меняет состояние и в итоге лопается. В отличие от обычного таймера, рядом стоит настоящий рынок: котировки AI-компаний, крипты и сводный «Индекс пузыря», посчитанный из этих котировок. Цифры настоящие, шутка живёт в подписях и состояниях.

## Operating Context

Статический сайт на GitHub Pages. Данные обновляет GitHub Actions по расписанию: скрипт тянет котировки (Yahoo Finance chart API для акций, CoinGecko для крипты, без ключей), считает сводный индекс и коммитит `data/market.json`; страница читает этот файл. Деплой собран из ветки `gh-pages`.

Посетитель чаще всего приходит с телефона, из мессенджера, по короткой ссылке. Страница должна читаться при первом открытии без прокрутки.

## Capabilities and Constraints

- Дедлайн настраивается пользователем, хранится в `localStorage` и передаётся ссылкой через параметр `?to=`.
- Два языка: русский по умолчанию, английский по переключателю.
- Графики: акции AI-компаний, крипта, сводный «Индекс пузыря».
- Данные обновляются автоматически, без API-ключей и без ручного труда.
- Только статические файлы, без сборки, фреймворка и серверного кода.
- Графики рисуются вручную на SVG, без библиотек.
- Незакрытые продуктовые факты: имя продукта (рабочее «ПУЗЫРЬ AI») не подтверждено.

## Brand Commitments

Рабочее название «ПУЗЫРЬ AI» пока не подтверждено пользователем. Голос: ироничный, добродушный, без злобы и без попытки кого-то обвинить. Шутка живёт в подписях, состояниях пузыря и реакции на клик, а не в мелких буквах. Имиджевых препятствий нет.

## Evidence on Hand

Настоящие котировки доступны без ключей: Yahoo Finance chart API для акций, CoinGecko (CORS разрешён) для крипты. Данных, которых у нас нет: отзывы, оценки рынка AI, «источники прогноза», любые упоминания реальных сделок и компаний как инвесторов. Всё перечисленное выдумано и подано как шутка, а не как факт.

## Product Principles

1. Время читается словами, а не считается в уме по цифрам. Человекочитаемый остаток обязан стоять на первом экране.
2. Цифры настоящие, шутка в подписях. Никаких выдуманных котировок.
3. Ответ на «когда лопнет» даётся за секунду, без прокрутки и без регистрации.
4. Ноль сборки, ноль ключей, ноль бэкенда. Ссылка работает вечно.
5. Пузырь показывает стресс рынка, а не украшает страницу.

## Accessibility & Inclusion

Проектный стандарт: контраст текста не ниже 4.5:1 для основного текста и 3:1 для крупного, полная работа с клавиатуры, тач-цели не меньше 44px, уважение `prefers-reduced-motion`, читаемость без JavaScript не требуется, но текст обратного отсчёта не должен зависеть от анимации.
