# ПУЗЫРЬ AI

Шуточный таймер обратного отсчёта до лопания ИИ-пузыря. Страница работает как
ночная метеостанция: слева прибор с пузырём под стеклом и шкалой давления, справа
человекочитаемый отсчёт, ниже барограф с настоящими котировками и журнал наблюдений.

Дедлайн фиксирован: **31 марта 2028, 23:59**. Дату нельзя установить, изменить или
подсунуть ссылкой: страница всегда считает до одной и той же даты.

## Что внутри

- **Настоящий отсчёт словами.** «1 год 5 месяцев 12 дней», а не «517 08:24:11».
  Точные секунды стоят рядом, но главный ответ на вопрос «когда лопнет» читается
  словами сразу, без прокрутки.
- **Настоящие котировки.** 14 бумаг AI-сегмента, S&P 500, Bitcoin и Ethereum.
  Источники: Yahoo Finance chart API и CoinGecko, без API-ключей.
- **Индекс пузыря.** Равновзвешенный композит из акций корзины, база 1000.
  Строится из тех же котировок, что и таблица.
- **Пузырь как прибор.** Он надувается по мере приближения дедлайна, меняет
  окраску, покрывается трещинами, а в ноль лопается с протоколом разрыва.
- **Два языка.** Русский по умолчанию, английский по кнопке.
- **Без сборки и без бэкенда.** Чистые HTML, CSS и JavaScript.

## Как обновляются данные

Статический сайт не умеет ходить в биржу сам, поэтому обновление делает CI:

```
GitHub Actions (cron каждые 30 минут)
   └─ node scripts/fetch-market.mjs   →  data/market.json
        └─ git commit + push в main
             └─ workflow pages.yml пересобирает и публикует сайт
```

Страница просто читает `data/market.json`. Если файла нет или он устарел, в
журнале честно пишется, что данных нет, а не рисуются выдуманные цифры.

Обновить данные локально:

```bash
node scripts/fetch-market.mjs
```

## Локальный запуск

```bash
python -m http.server 8099
# затем открыть http://127.0.0.1:8099/
```

Нужен именно HTTP-сервер: страница читает `data/market.json` через `fetch`,
а с `file://` браузер его заблокирует.

## Шрифты

Шрифты лежат в `fonts/` и подключаются локально через `fonts.css`, чтобы сайт не
зависел от внешнего CDN. Обновить их:

```bash
node scripts/fetch-fonts.mjs
```

Jost и JetBrains Mono, лицензия SIL Open Font License.

## Публикация

Деплой идёт через GitHub Actions: `pages.yml` собирает статику и выкладывает её
в Pages, `market-data.yml` обновляет котировки. Сайт живёт по адресу
`https://<user>.github.io/<repo>/`.

## Структура

```
index.html              разметка
styles.css              визуальная система
app.js                  отсчёт, график, журнал, звук, лопание
fonts.css, fonts/       локальные шрифты
data/market.json        котировки и серии (обновляет CI)
scripts/fetch-market.mjs сбор данных
scripts/fetch-fonts.mjs скачивание шрифтов
scripts/probe.mjs       проверка вёрстки в headless Edge
```

## Шутка и факты

Цифры настоящие. Подписи в журнале, шутки в протоколе разрыва и слова «источник
прогноза» — это сатира наблюдателя, а не утверждения о компаниях и не
инвестиционный совет.
